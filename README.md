# Spice St Market — Faithful Webflow Port

Static port of [spicest.webflow.io](https://spicest.webflow.io/) (Webflow site `665ec1cc5ff6a46b977004bc`) for Cloudflare Workers. Markup, shared CSS, and custom-code animations (Swiper / GSAP / Materialize / Typed / particles) are preserved from the published Webflow site so the Worker matches [spicestmarket.com](https://spicestmarket.com/). On top of that sit a recipe section (one recipe per spice blend), a responsive image pipeline, and a thin interaction layer.

**Live:** [https://spicestmarket.elombe.workers.dev](https://spicestmarket.elombe.workers.dev)  
**Repo:** [github.com/SWFTstudios/spicestmarket](https://github.com/SWFTstudios/spicestmarket)

Pushes to `main` auto-build and deploy via Cloudflare Workers Builds (`npm run build` → `npx wrangler deploy`).

## Setup

```bash
npm install
npm run scrape    # pull spicest.webflow.io pages + assets → source/
npm run build     # rewrite URLs, optimize images, render recipes, emit dist/
npm run measure   # (after a build) record real rendered image sizes → src/data/image-sizes.json
npm run dev       # preview dist/ at http://localhost:4174
npm run compare   # screenshot local vs webflow.io vs live
npm run deploy    # build + deploy to Cloudflare Workers
```

| Path | Purpose |

| `source/` | Untouched scrape of published Webflow pages + CDN assets |

| `scripts/` | scrape, build, measure, compare |

## Pages

Home, About, Shop, Gallery, Recipes (index + `/recipes/<blend>/` × 14), 404. `/contact` redirects to `/#footer`; old Webflow `/recipe/*` links 301 to the matching blend recipe.

## Recipes

Every blend in the three packs has a recipe at `/recipes/<slug>/`, linked from the **Recipes** mega menu in the nav. To add or edit one, change `src/data/recipes.json` and rebuild. Each recipe page has:

- Street-sign hero ("Meet me by Roasted Ave & Potato Blvd") with the blend's tagline from the tin
- Servings scaler (fractions + unit conversion), ingredient and step checklists saved per device
- Tap-to-start step timers with a floating timer dock and a chime
- Cook mode: full-screen step-by-step, keeps the screen awake, arrow keys / swipe to move
- "Shake the tin" easter egg, the blend card with Amazon link, and next-stop recipes from the same pack
- `Recipe` structured data for Google rich results, and a print stylesheet

## Performance

- Every local raster image is re-encoded to WebP at 480/960/1440/1920 px with a content hash (cached forever via `_headers`)
- `sizes` come from real layout measurements (`npm run measure`), so phones download phone-sized images; unmeasured lazy images use `sizes="auto"`
- CSS background textures are capped at 1600 px
- Speculation Rules prefetch pages on hover (hover-prefetch fallback elsewhere) + cross-document View Transitions
- Unused Swiper 7 bundle and cross-origin Amazon/Instagram prefetches are dropped

Re-run `npm run build && npm run measure && npm run build` after big layout changes in Webflow.

## Motion

- Webflow custom code owns carousels, spice-pack tabs, typed hero, 3D shelves
- Optional Lenis smooth scroll (disabled under `prefers-reduced-motion`)
- Cross-document View Transitions via CSS `@view-transition`; recipe photos morph from the index card into the recipe hero
- Spice-fleck "sneeze" bursts on Amazon CTAs ("If you ain't sneezin, you ain't seasonin")
- All new motion respects `prefers-reduced-motion`
